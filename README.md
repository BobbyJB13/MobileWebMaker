# Mobile Web Maker 🚀📱

A lightweight, standalone HTML IDE designed entirely for mobile devices. Build, test, and manage web projects directly from your smartphone with zero friction and no terminal commands required.

## ✨ Features
- **Standalone Single-File App**: Fully self-contained HTML solution.
- **Modular UI**: Project archiving, code snippets, and a built-in live preview engine.
- **Mobile-First**: Optimized for touchscreens and mobile browsers (e.g., via Pydroid 3 workflows).

## 🌐 Open Source & Live
Everyone can use, test, and modify this tool directly via GitHub Pages. No complex setup or Git installation needed!
